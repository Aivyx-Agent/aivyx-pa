# Contributor License Agreement

**This file has moved.** As of 2026-09-24, Aivyx PA accepts contributions
under the **org-wide** Aivyx-Agent Contributor License Agreement rather than
a project-scoped one:

> **[Aivyx-Agent Contributor License Agreement](https://github.com/Aivyx-Agent/aivyx-ecosystem/blob/main/docs/legal/CLA.md)**

Nothing about how you accept it changes: a `Signed-off-by` trailer on each
commit (`git commit -s`) still certifies both the Developer Certificate of
Origin and acceptance of the CLA for that contribution — see
[`CONTRIBUTING.md`](CONTRIBUTING.md).

**Why the change:** every Aivyx-Agent repository is converging on BUSL-1.1
(see [`aivyx-ecosystem/LICENSING.md`](https://github.com/Aivyx-Agent/aivyx-ecosystem/blob/main/LICENSING.md)),
and one CLA covering contributions to any repository in the organization is
simpler than a separately-scoped CLA per repo. Aivyx PA's own CLA (v1.0,
2026-06-19–2026-09-24) is superseded by the org-wide version; its terms were
substantively the same — this is a scope change, not a rights change. The
retired text remains available in git history at this path.
